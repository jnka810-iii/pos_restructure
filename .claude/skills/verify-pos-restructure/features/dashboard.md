# แท็บสรุปภาพรวม

แท็บสรุปภาพรวมแสดงการ์ดสถิติสี่ใบและกราฟสี่รูปที่สรุปคำขอทั้งหมด กราฟวาดด้วย Chart.js จากไลบรารีในเครื่อง ไม่ได้ต่ออินเทอร์เน็ต แท็บนี้คือส่วนที่ `test_api.py` ครอบไม่ถึง เพราะต้องขับเบราว์เซอร์จริง จึงเป็นเหตุผลหลักที่สคิลนี้มีอยู่

## Sub-features

- `dash-cards` การ์ดสถิติสี่ใบคือ คำขอทั้งหมด ได้รับอนุมัติ ค่าตอบแทนเฉลี่ย และอัตราอนุมัติ
- `dash-charts` กราฟสี่รูปวาดได้จริง คือสถานะคำขอแบบโดนัท และแท่งสามรูปตามประเภทตำแหน่ง กอง และระดับตำแหน่ง
- `dash-counts-positions` กราฟสามรูปนับจำนวน **ตำแหน่ง** ไม่ใช่จำนวนคำขอ และหัวกราฟบอกจำนวนทั้งสองไว้
- `dash-refresh` ตัวเลขและกราฟเปลี่ยนตามข้อมูลที่มีจริง เมื่อกลับเข้าแท็บหลังข้อมูลเปลี่ยน
- `dash-empty` สภาพที่ยังไม่มีคำขอ

## How to get to it (user POV)

- กดแท็บ `สรุปภาพรวม`

## Driving it with control_pos.py

Preconditions:

- `$POS doctor` ผ่านทั้ง 8 ข้อ
- มีคำขอตั้งต้นสองใบ แต่ละใบมีตำแหน่งใหม่หนึ่งตำแหน่ง ใบหนึ่งสถานะ `อนุมัติ` ค่าตอบแทน `45000.50` อีกใบสถานะ `อยู่ระหว่างพิจารณา` ค่าตอบแทน `28000`
- เปิดแอปด้วย `$POS browser open`

- **เข้าแท็บ** สั่ง `$POS browser click --text "สรุปภาพรวม"` แล้ว `$POS browser read --select '#stat-cards' --wait-text "คำขอทั้งหมด"` ผลที่ได้คือ `active_tab` เป็น `สรุปภาพรวม`
- **การ์ดสถิติ** ในผลเดิม `text` มีตัวเลข `2` คู่กับ `คำขอทั้งหมด` และ `1` คู่กับ `ได้รับอนุมัติ` และ `36,500.25 บาท` คู่กับ `ค่าตอบแทนเฉลี่ย` และ `50.0%` คู่กับ `อัตราอนุมัติ` ค่าเฉลี่ยคือค่ากลางของ `45000.50` กับ `28000` จัดรูปแบบตัวเลขแบบไทย
- **กราฟวาดได้จริง** ถามจาก Chart.js ว่ามี instance ผูกกับ canvas ทั้งสี่ตัวหรือไม่ สั่ง `$POS browser read --expr "['chart-status','chart-type','chart-div','chart-level'].map(i=>{const c=Chart.getChart(document.getElementById(i));return {id:i,drawn:!!c,type:c&&c.config.type,labels:c&&c.data.labels,data:c&&c.data.datasets[0].data}})"` ทั้งสี่ตัวมี `drawn` เป็น `true` และ `chart-status` เป็น `doughnut` ส่วนอีกสามตัวเป็น `bar`
- **ป้ายและค่าในกราฟตรงกับข้อมูล** ในผลเดิม `chart-status` มีป้าย `อนุมัติ` กับ `อยู่ระหว่างพิจารณา` ป้ายละ `1` และ `chart-type` มีป้าย `วิชาการ` กับ `ทั่วไป` และ `chart-div` มีป้าย `กองการเจ้าหน้าที่` กับ `กองคลัง` และ `chart-level` มีป้าย `ชำนาญการพิเศษ` กับ `อาวุโส`
- **หัวกราฟบอกหน่วยที่นับ** สั่ง `$POS browser read --expr "['chart-type','chart-div','chart-level'].map(i=>Chart.getChart(document.getElementById(i)).options.plugins.title.text)"` ทั้งสามหัวกราฟลงท้ายด้วย `(2 ตำแหน่ง จาก 2 คำขอ)`
- **ตัวเลขเปลี่ยนตามข้อมูล** เพิ่มคำขอที่มีตำแหน่งใหม่สองตำแหน่งในใบเดียว สั่ง `$POS api POST api/positions --data '{"sec1_rows":"[{\"s1_type\":\"บริหาร\",\"s1_level\":\"ระดับสูง\",\"s1_no\":\"901\",\"s1_division\":\"กองแผนงาน\"},{\"s1_type\":\"บริหาร\",\"s1_level\":\"ระดับต้น\",\"s1_no\":\"902\",\"s1_division\":\"กองแผนงาน\"}]","p4_status":"อนุมัติ"}'` แล้วกลับเข้าแท็บเพื่อให้โหลดใหม่ สั่ง `$POS browser click --text "กรอกข้อมูล"` แล้ว `$POS browser click --text "สรุปภาพรวม"` แล้วอ่านหัวกราฟซ้ำ ลงท้ายด้วย `(4 ตำแหน่ง จาก 3 คำขอ)` ซึ่งพิสูจน์ว่ากราฟนับตำแหน่ง ไม่ใช่นับคำขอ
- **สภาพว่าง** ลบข้อมูลให้หมดแล้วดูแท็บนี้ สั่ง `$POS data reset --apply` แล้ว `$POS browser click --text "กรอกข้อมูล"` แล้ว `$POS browser click --text "สรุปภาพรวม"` แล้ว `$POS browser read --select '#stat-cards'` การ์ดคำขอทั้งหมดเป็น `0` และอัตราอนุมัติเป็น `-` และค่าตอบแทนเฉลี่ยเป็น `-` และกราฟยังมี instance อยู่แต่ไม่มีป้าย ตรวจด้วยคำสั่ง `--expr` เดิม
- **หลักฐาน** สั่ง `$POS browser shot --name dashboard --with-text --full-page` ตอนมีข้อมูลสามใบ ภาพต้องเห็นการ์ดสถิติและกราฟทั้งสี่รูป และ `$POS browser shot --name dashboard-empty --with-text` ตอนสภาพว่าง
- **คืนสภาพ** สั่ง `$POS data seed`

## Gotchas

- กราฟถูกวาดเมื่อ **เข้าแท็บ** เท่านั้น การเปลี่ยนข้อมูลผ่าน API แล้วอ่านซ้ำทั้งที่ยังอยู่ในแท็บนี้จะได้ค่าเก่า ต้องออกไปแท็บอื่นแล้วกลับเข้ามา
- `Chart.getChart(canvas)` คืน instance ที่ผูกกับ canvas นั้น ใช้ตรวจว่าวาดสำเร็จจริง การเห็น canvas อยู่ใน DOM ไม่ได้แปลว่ากราฟวาดได้ ถ้า Chart.js โหลดไม่มา `typeof Chart` จะเป็น `undefined` และคำสั่ง `--expr` จะโยน error ซึ่งเป็นสัญญาณว่าปัญหาอยู่ที่ไลบรารี ไม่ใช่ที่ข้อมูล
- ภาพหน้าจออย่างเดียวพิสูจน์กราฟไม่ได้ กราฟที่ว่างเปล่ากับกราฟที่พังมองออกยาก ให้เก็บผลของ `Chart.getChart` คู่กับภาพทุกครั้ง
- กราฟสามรูปนับจำนวนตำแหน่ง คำขอที่มีสามตำแหน่งนับเป็นสาม การ assert ด้วยจำนวนคำขอจะผิดทันทีที่คำขอใบใดมีมากกว่าหนึ่งตำแหน่ง
- ค่าตอบแทนเฉลี่ยนับเฉพาะคำขอที่กรอกค่าตอบแทนไว้ ไม่ได้หารด้วยจำนวนคำขอทั้งหมด
- ตัวเลขค่าตอบแทนจัดรูปแบบด้วย `toLocaleString('th-TH')` จึงมีเครื่องหมายคั่นหลักพัน การเทียบกับ `45000.5` ตรงๆ จะไม่ตรง
- แถวที่ว่างทั้งแถวในส่วนที่ 1 ไม่ถูกนับ `filledRows` ข้ามแถวเปล่า ทั้งในกราฟและในตาราง
