# ผู้บันทึกเก็บชื่อที่คัดลอกไว้ ไม่ใช่ตัวอ้างอิงไปยังบัญชี

คอลัมน์ `created_by` และ `updated_by` ในตาราง `positions` เก็บ **ชื่อแสดงผลของผู้ใช้งาน ณ ขณะที่บันทึก** เป็นข้อความตรง ๆ ไม่ได้เก็บ id ที่ชี้ไปยังแถวในตาราง `users` เพราะชื่อผู้บันทึกบนคำขอคือข้อเท็จจริงทางประวัติศาสตร์ว่า "ใครเป็นคนบันทึกตอนนั้น" ไม่ใช่ตัวชี้ไปยังคนที่ยังทำงานอยู่ ผู้ดูแลจึงลบบัญชีของคนที่ย้ายออกได้ทันทีโดยประวัติบนคำขอเดิมไม่กำพร้า และเข้ากับแบบแผนของฐานข้อมูลนี้ซึ่งไม่มี foreign key เลยสักตัว (ตำแหน่งในแต่ละส่วนก็เก็บเป็น JSON ฝังอยู่ในแถวเดียวกัน)

ราคาที่จ่ายคือถ้าผู้ใช้งานเปลี่ยนชื่อหรือนามสกุล คำขอที่บันทึกไว้ก่อนหน้าจะยังแสดงชื่อเดิม ซึ่งยอมรับได้ เพราะเอกสารราชการที่ลงนามไว้แล้วก็ไม่ได้เปลี่ยนชื่อตามเจ้าของย้อนหลังเหมือนกัน

คำขอที่บันทึกจากเครื่องแม่ข่ายซึ่งไม่ต้องเข้าสู่ระบบ (ดู [ADR 0001](./0001-login-only-for-other-machines.md)) เก็บคำว่า `เครื่องแม่ข่าย` แทนชื่อคน ส่วนคำขอที่บันทึกไว้ก่อนมีระบบเข้าสู่ระบบมีค่าว่าง ทั้งสองอย่างแยกออกจากกันได้ด้วยตาเปล่า
