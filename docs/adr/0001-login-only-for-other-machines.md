# ด่านเข้าสู่ระบบยกเว้นคำขอที่มาจากเครื่องแม่ข่ายเอง

> [ADR 0003](0003-server-mode-requires-a-login-from-everyone.md) ยกเลิกข้อยกเว้นนี้เฉพาะตอนที่แอปเปิดรับจากภายนอก ซึ่งเป็นกรณีที่ย่อหน้าสุดท้ายของเอกสารนี้เตือนไว้เอง ข้อความที่เหลือยังใช้กับโหมดเดสก์ท็อปและไฟล์ `.exe` ตามเดิม

แอปนี้เสิร์ฟให้คนในวง LAN ผ่าน `run_server.bat` และเสิร์ฟให้ตัวเองผ่าน `run.bat` กับ `run_browser.bat` เราบังคับเข้าสู่ระบบเฉพาะคำขอที่ `request.remote_addr` ไม่ใช่ loopback คำขอจาก `127.0.0.1` และ `::1` ผ่านด่านไปเลย เพราะคนที่นั่งอยู่หน้าเครื่องแม่ข่ายเปิดไฟล์ `pos_restructure.db` ด้วยโปรแกรมอะไรก็ได้อยู่แล้ว การบังคับให้เจ้าของเครื่องพิมพ์รหัสผ่านจึงไม่ได้เพิ่มการป้องกันอะไรเลย มีแต่เพิ่มขั้นตอนทุกครั้งที่เปิดแอป

นี่คือความตั้งใจ ไม่ใช่ช่องโหว่ที่ลืมปิด ถ้าวันหนึ่งแอปถูกวางไว้หลัง reverse proxy หรือมีอะไรที่ส่งต่อคำขอจากเครื่องอื่นมาเป็น loopback แทน ข้อยกเว้นนี้จะกลายเป็นช่องโหว่ทันที และต้องเปลี่ยนเป็นการเช็กอย่างอื่น

ผลที่ตามมาอีกสองอย่าง: `test_api.py` ใช้ `test_client()` ซึ่ง Flask ตั้ง `REMOTE_ADDR` เป็น `127.0.0.1` ให้เอง เทสเดิมทุกตัวจึงไม่ต้องรู้จักการเข้าสู่ระบบ เทสที่ตั้งใจทดสอบด่านต้องตั้ง `REMOTE_ADDR` เป็นเลขในวงเอง และการเปิดแอปจากเครื่องแม่ข่ายโดยพิมพ์ IP ของตัวเอง (ไม่ใช่ `127.0.0.1`) จะโดนด่านเหมือนเครื่องอื่น ซึ่งถูกต้องแล้ว เพราะเซิร์ฟเวอร์แยกไม่ออกว่าคำขอนั้นมาจากใคร
