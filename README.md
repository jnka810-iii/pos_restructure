# ระบบข้อมูลการปรับปรุงการกำหนดตำแหน่งในสำนักนายกรัฐมนตรี

แอปบันทึกข้อมูลแบบ บอ.1 สำหรับคำขอปรับปรุงการกำหนดตำแหน่ง สร้างด้วย Flask กับ SQLite และเปิดเป็นหน้าต่างเดสก์ท็อปผ่าน pywebview ได้ หรือ build เป็นไฟล์ `.exe` ไฟล์เดียวสำหรับ Windows

## ความสามารถ

- กรอกข้อมูลแบบ บอ.1 ครบ 5 ส่วน
  1. คำขอกำหนดตำแหน่ง (ใหม่)
  2. ตำแหน่งที่นำมาปรับปรุงการกำหนดตำแหน่ง
  3. การยุบเลิกตำแหน่งเพื่อควบคุมค่าใช้จ่าย
  4. การพิจารณาของ อกพ. (ครั้งที่ประชุม วันที่ มติ สถานะคำขอ วันที่มีผล หมายเหตุ)
  5. ค่าตอบแทนเฉลี่ยคงเหลือ

  ส่วนที่ 1 ถึง 3 เพิ่มได้หลายตำแหน่งต่อคำขอ
- แนบเอกสารประกอบได้หนึ่งไฟล์ต่อรายการ รองรับ PDF, Word และ Excel ขนาดไม่เกิน 10 MB
- แท็บรายการทั้งหมด สำหรับแก้ไขและลบรายการ
- แท็บสรุปภาพรวม แสดงกราฟด้วย Chart.js
- ส่งออกเป็น CSV, JSON และพิมพ์หรือบันทึกเป็น PDF ทีละรายการ

## ความต้องการของระบบ

- Windows 10 หรือ 11
- Python 3.10 ขึ้นไป
- อินเทอร์เน็ต ตอนนี้หน้าเว็บยังโหลด Bootstrap, Font Awesome, Chart.js และฟอนต์ Sarabun จาก CDN (ดูหัวข้อ [ข้อจำกัดที่ทราบ](#ข้อจำกัดที่ทราบ))
- Node.js (ไม่บังคับ) ใช้เฉพาะเทสที่รันฟังก์ชัน JavaScript ของหน้าเว็บ ถ้าไม่มี เทสกลุ่มนั้นจะถูกข้าม

## ติดตั้ง

```bat
cd pos_restructure
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`pyinstaller` ใน `requirements.txt` ใช้เฉพาะตอน build `.exe` ถ้าแค่รันแอปไม่ต้องติดตั้งก็ได้

## วิธีรัน

มีไฟล์ `.bat` ให้ดับเบิลคลิก 3 แบบ ทุกไฟล์ใช้ Python ใน `.venv` ก่อน ถ้าไม่มีจึงใช้ `python` ของเครื่อง

| ไฟล์ | โหมด | เข้าถึงจาก |
| --- | --- | --- |
| `run.bat` | เดสก์ท็อป เปิดหน้าต่าง pywebview | เครื่องนี้เท่านั้น |
| `run_browser.bat` | เปิดในเว็บเบราว์เซอร์ปกติ | `http://127.0.0.1:5050` เครื่องนี้เท่านั้น |
| `run_server.bat` | เซิร์ฟเวอร์ในวง LAN | `http://<IP เครื่องนี้>:5050` ทุกเครื่องในเครือข่าย |

ถ้าไม่ได้ติดตั้ง pywebview คำสั่ง `python app.py` จะรันเป็นเว็บเซิร์ฟเวอร์ที่ `http://127.0.0.1:5050` แทน

> **ข้อควรระวังของโหมด LAN:** แอปไม่มีระบบล็อกอิน ทุกคนที่เข้าถึงพอร์ต 5050 ได้จะอ่าน แก้ไข และลบข้อมูลได้ทั้งหมด ใช้เฉพาะในเครือข่ายที่ไว้ใจได้

## Build เป็น .exe

```bat
.venv\Scripts\pyinstaller.exe --noconfirm --onefile --windowed ^
  --add-data "templates;templates" ^
  --add-data "static;static" ^
  --hidden-import webview ^
  --name "PosRestructure" app.py
```

`--add-data "static;static"` คือไลบรารีหน้าเว็บ ถ้าไม่ใส่บรรทัดนี้ `.exe` จะไม่มี Bootstrap, Chart.js, Font Awesome และฟอนต์ Sarabun ติดไปด้วย และแท็บสรุปภาพรวมจะใช้งานไม่ได้

ไฟล์ที่ได้อยู่ใน `dist\PosRestructure.exe` ตอนรัน แอปจะสร้างฐานข้อมูล ไฟล์ log และโฟลเดอร์ `uploads` ไว้ข้างไฟล์ `.exe`

## ข้อมูลและฐานข้อมูล

ข้อมูลทั้งหมดอยู่ในตาราง `positions` ตารางเดียวใน `pos_restructure.db`

- ส่วนที่ 1 ถึง 3 เก็บเป็น JSON array ในคอลัมน์ `sec1_rows`, `sec2_rows`, `sec3_rows`
- ส่วนที่ 4 และ 5 เก็บแยกคอลัมน์ ขึ้นต้นด้วย `p4_` และ `p5_`
- ไฟล์แนบเก็บชื่อไฟล์ที่ระบบตั้งใหม่ (UUID) ใน `file_name` และชื่อเดิมใน `file_orig_name`
- `created` และ `updated` เก็บเป็น ISO 8601 ค.ศ. หน้าเว็บแปลงเป็นรูปแบบไทยตอนแสดงผล

ตอนเริ่มแอป `init_db()` สร้างตารางและเพิ่มคอลัมน์ที่ขาดให้อัตโนมัติ และแปลง timestamp รูปแบบเก่า `DD/MM/YYYY HH:MM` เป็น ISO ให้ ไม่ต้องรัน migration เอง

**สำรองข้อมูล:** ปิดแอปก่อน แล้วคัดลอก `pos_restructure.db` กับโฟลเดอร์ `uploads/` ไปเก็บไว้ด้วยกัน

## API

ทุก endpoint ตอบเป็น JSON ข้อความ error เป็นภาษาไทยในรูป `{"ok": false, "error": "..."}`

| Method | Path | ใช้ทำอะไร |
| --- | --- | --- |
| GET | `/api/positions` | ดึงรายการทั้งหมด เรียงจากใหม่ไปเก่า |
| POST | `/api/positions` | เพิ่มรายการ |
| PUT | `/api/positions/<id>` | แก้ไขรายการ ตอบ 404 ถ้าไม่มี id นี้ |
| DELETE | `/api/positions/<id>` | ลบรายการพร้อมไฟล์แนบ |
| DELETE | `/api/positions` | ลบทุกรายการพร้อมไฟล์แนบทั้งหมด |
| POST | `/api/upload` | อัปโหลดไฟล์แนบ (multipart field ชื่อ `file`) |
| GET | `/uploads/<ชื่อไฟล์>` | เปิดไฟล์แนบ |
| GET | `/api/ping` | เช็กว่าเซิร์ฟเวอร์ทำงานอยู่ |

คำขอที่เปลี่ยนข้อมูลและส่ง header `Origin` มาจากเว็บไซต์อื่นจะถูกปฏิเสธด้วย 403 เพื่อกัน CSRF

## เทส

```bat
.venv\Scripts\python.exe test_api.py
```

เทสใช้ฐานข้อมูลและโฟลเดอร์อัปโหลดชั่วคราว ไม่แตะข้อมูลจริง และจบด้วยสรุปจำนวนเทสที่ผ่าน คืนค่า exit code 1 ถ้ามีเทสไม่ผ่าน

### ตรวจว่าใช้งานออฟไลน์ได้

```bat
.venv\Scripts\python.exe verify_offline.py
```

สคริปต์เปิดแอปบนพอร์ตว่าง แล้วสั่ง Edge หรือ Chrome แบบ headless ให้เปิดหน้านั้นโดยทุกโฮสต์นอกจาก 127.0.0.1 หาที่อยู่ไม่เจอ ซึ่งเป็นสภาพเดียวกับเครื่องที่ไม่มีเน็ต แล้ววัดจากในเบราว์เซอร์ว่า Chart.js, Bootstrap, ไอคอน และฟอนต์ไทยมาครบ ภาพหน้าจอที่ได้อยู่ในโฟลเดอร์ temp สั่งที่อื่นได้ด้วย `--shot`

## สคริปต์ดูแลระบบ

ทั้งสองสคริปต์เป็น dry-run โดยค่าเริ่มต้น แสดงแค่สิ่งที่จะทำ ต้องใส่ `--apply` จึงจะทำจริง

```bat
REM ลบไฟล์แนบที่ไม่มีรายการไหนอ้างถึง
.venv\Scripts\python.exe cleanup_orphans.py
.venv\Scripts\python.exe cleanup_orphans.py --apply

REM ลบคอลัมน์ที่โค้ดไม่ใช้แล้ว (สำรองฐานข้อมูลเป็น .bak ให้ก่อนเสมอ)
.venv\Scripts\python.exe migrate_schema.py
.venv\Scripts\python.exe migrate_schema.py --apply
```

ส่วน `vendor_assets.py` ดาวน์โหลดไลบรารีหน้าเว็บลง `static/vendor` ใหม่ทั้งโฟลเดอร์ ต้องต่อเน็ตตอนรัน ใช้เมื่อขึ้นเวอร์ชัน Bootstrap, Chart.js, Font Awesome หรือฟอนต์ Sarabun โดยแก้ตาราง `ASSETS` ในสคริปต์ก่อน แล้วรัน `verify_offline.py` ซ้ำ

```bat
.venv\Scripts\python.exe vendor_assets.py
```
